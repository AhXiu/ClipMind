# Android 个人知识库体验调整

本轮仅修改本地代码与测试，不部署、不调用真实模型、不使用真实 Key。保留原有绿色纸张风格，以及已有多服务商接入、密钥隔离和任务快照。

## 八项落地

| 方向 | 当前实现 |
| --- | --- |
| 以原文和个人理解为主 | 详情顺序为原文、我的想法、相关卡片、AI 辅助。无 AI 结果也可保存想法。 |
| 减少一级入口 | 默认卡片库；底栏仅卡片、主题、回顾。右上角进入状态中心和设置，统一 + 输入、粘贴、语音。分享和语音结果打开同一记录框。 |
| 查找不中断 | 查询、来源/时间/AI 筛选、排序、选择集合由 ViewModel 在内存保留；列表滚动状态提升到详情页之外。搜索覆盖原文、标签、个人想法、来源应用及链接，并显示匹配片段和高亮。 |
| 分清保存与处理 | 本机保存状态与 AI、同步状态分离。详情主 AI 动作为“帮我整理”，重试、再生成、云端结果和深度能力位于高级区；错误保持可见。 |
| 手动主题优先 | 主题支持创建、改名、主题笔记、添加/移出多张卡片和删除。删除主题不删除卡片，同一卡片可加入多个主题。AI 归纳笔记独立保存、按需展开；队列在状态中心，导出在设置。 |
| 渐进配置 | 空库引导记录第一张卡片，无需 Shizuku/模型。新安装默认关闭 AI 及自动提交；保留已存在的明确配置和历史安装默认值。设置按采集、AI、数据与备份、提醒分组。模型先显示当前、最近和常用，保留全部目录搜索及自定义 ID。 |
| 温和回顾 | 今日卡片、想法记录、每周回顾、Notion 分区。今天跳过只调整到明天，不增加完成次数、不改变记忆参数。带草稿完成回顾时，在同一事务中保存想法与回顾进度。 |
| 统一与保护 | 卡片列表长按多选，删除是显式操作且仍需确认；外发和费用确认不省略。高级术语默认收起，主题未保存退出需确认。 |

## 数据与隐私

- Room 仍为 v7，复用 `reader_documents` 存储 `topic` 和 `private_draft`，无破坏性迁移、无清库。
- 主题与草稿正文使用现有 Keystore 加密。搜索内容只在 ViewModel 内存中存在，不存入明文 Bundle/Preferences；进程重建后不恢复搜索词。数字滚动位置可以通过 Compose 保存。
- 新卡片草稿与想法草稿自动加密保存，保存状态会在页面显示。磁盘/加密失败不假报成功；等待“草稿已加密保存”后再关闭应用。进程在写入完成前被强制终止，仍可能丢失最后一次输入。
- 本地写入独立于远程 AI 任务，按顺序执行。后来的自动保存不会覆盖已经完成的保存/清理；清理仅删除仍与已保存文本一致的草稿。
- 分享内容先等待旧草稿恢复，再合并；损坏草稿不自动覆盖。部分损坏不妨碍其他草稿恢复，页面提供重试入口。原文旧版本和已删除卡片的未完成想法可在“回顾 → 想法记录”中查看、复制或明确删除。
- 个人想法与主题笔记不会因“帮我整理”被自动外发。语音由用户设备的系统识别服务处理，可能联网，入口有说明。
- 主题更新使用版本校验和事务；新加入的卡片必须仍存在。已删除卡片的旧主题引用可保留或手动清理，绝不据此恢复卡片。
- Obsidian ZIP 增加主题 JSON，继续包含卡片、周报、个人想法和原始备份，默认不含草稿。仅有主题等独立文档时也可导出 ZIP。CSV/纯文本仍只导出卡片。导出为明文，需保存到可信位置。
- 删除原卡片不会删除主题笔记、想法、周报、草稿、历史导出或远端副本；删除确认中保留此边界。未实现整库物理备份/恢复，不能把本轮导出理解为可自动还原的数据库备份。

## 验证

自动验证命令（本地、假地址）：

```sh
cd android
env JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-21.jdk/Contents/Home ANDROID_HOME=/tmp/clipmind-android-sdk ./gradlew testDebugUnitTest lintDebug assembleDebug -Pclipmind.baseUrl=https://example.invalid/
python3 scripts/check_migration.py
```

新增 JVM 用例覆盖：主题密文与版本冲突、成员有效性、删除隔离、草稿恢复/部分损坏/条件清理、初始化和写入顺序、回顾跳过/跨夏令时、扩展搜索/匹配片段、安装默认值和最近模型。

仍需真机人工验收，不将 JVM 和构建结果冒充完整 UI 验收：

1. 在无 Shizuku、无 Token/Key、新安装环境创建卡片并写想法，确认无网络请求且退出重进后可读。
2. 用足够长的卡片列表验证搜索/筛选后打开详情、返回、切换页面、旋转屏幕；进程被回收后搜索词应清空，不从明文状态恢复。
3. 输入草稿后立即分享另一段文本；验证恢复顺序、连续输入后保存、存储失败及恢复，不丢失原草稿。
4. 开始模拟耗时 AI 任务后仍可保存想法和主题；无真实外部 Key，无实际计费请求。
5. 带想法完成回顾、跳过今天、切到明天；确认已完成计数与重复点击行为，不要求清空草稿。
6. 创建/编辑/删除主题，检查同卡多主题、已删除卡片引用、版本冲突、无卡片主题导出和未完成草稿排除。
7. 在 320dp 窄屏、横屏、键盘展开、大字体及 TalkBack 下检查记录框、模型搜索框、筛选和多选操作。模型下拉框长目录与自定义值均可达。
8. 所有发送、自动任务授权、删除确认、Key 隔离与失败状态均仍生效。

## 人工渐进启用

1. 本地自动验证通过后，由维护者使用合成数据在内部测试设备完成上述清单，不连接生产后端。
2. 产品和安全负责人确认信息架构、隐私默认值、外发提示、旧用户设置保留和数据兼容性后，人工批准小范围测试。
3. 小范围测试仅邀请明确知情的用户；关注丢稿、误发送、找不到入口、输入遮挡和迁移失败。不得记录正文、搜索词或 Key 作为诊断日志。
4. 达标后再由负责人决定扩大范围；实际渠道发布、环境配置和任何线上切换必须另行审批与二次授权。代理不执行发布。
5. 异常时停止扩大范围，不清库、不自动降级数据库。任何恢复版本或数据处理由人工评估、备份并授权后执行。
